# Code Templates

Copy-paste starters for common patterns. Reduces errors and ensures consistency.

## Available Templates

| Template | Use For |
|----------|---------|
| `service.go.tmpl` | Business logic service |
| `handler.go.tmpl` | HTTP handler (Gin) |
| `schema.go.tmpl` | Ent database entity |
| `resolver.go.tmpl` | GraphQL resolver pattern |

## Usage

1. Copy the template content
2. Replace placeholders: `{{Name}}`, `{{name}}`, `{{Package}}`
3. Adjust fields/methods for your use case
