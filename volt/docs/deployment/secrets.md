# secrets CLI

**Path:** `webapp/cmd/secrets/`
**Purpose:** CLI commands for managing GitHub repository secrets from local `.github/.secrets` file.

## Overview

The `secrets` CLI provides commands to:
- Base64 encode `.env.prod` and sync to GitHub secrets
- Push all secrets from `.github/.secrets` to GitHub repository

## Commands

### update

Base64 encode `.env.prod`, update `.github/.secrets`, and push `ENV_PROD_B64` to GitHub.

```bash
# Via task
task secrets:update

# Direct
go run ./webapp/cmd/secrets update
```

**What it does:**
1. Reads `.env.prod` file
2. Base64 encodes the content
3. Updates `ENV_PROD_B64` in `.github/.secrets`
4. Pushes `ENV_PROD_B64` to GitHub secrets

### push

Parse `.github/.secrets` and push all secrets to GitHub.

```bash
# Via task
task secrets:push

# Direct
go run ./webapp/cmd/secrets push
```

**What it does:**
1. Parses `.github/.secrets` using godotenv
2. Skips `GITHUB_TOKEN` and `GITHUB_ACTOR` (only needed for local `act` testing)
3. Pushes each secret to GitHub using `gh secret set`

## File Format

The `.github/.secrets` file uses standard dotenv format:

```env
# Comments are supported
KEY=value
MULTILINE_KEY="line1
line2
line3"
```

## Dependencies

- `github.com/joho/godotenv` - For parsing dotenv files
- `github.com/spf13/cobra` - For CLI framework
- `gh` CLI - GitHub CLI must be installed and authenticated

## Skipped Secrets

These secrets are skipped when pushing (only needed for local `act` testing):
- `GITHUB_TOKEN` - Auto-generated by GitHub Actions
- `GITHUB_ACTOR` - Auto-set by GitHub Actions

## Related Files

- `.github/.secrets` - Local secrets file (git-ignored)
- `.github/.secrets.example` - Template for secrets file
- `.env.prod` - Production environment variables
- `Taskfile.yml` - Task definitions (`secrets:update`, `secrets:push`)
