### Added
- `volt/docs/guides/configuration.md` — the full configuration flow: layers with live before/after `explain` output, the load pipeline, what `Derive()` computes, the validation rules, secret masking, per-binary load points, and the gotchas.
- `task config:check` / `config:explain` / `config:document`, and the matching `config` command on the application CLI. `check` validates the whole configuration **without constructing the application** and reports every problem at once, so a misconfigured deploy is one fix rather than one fix per restart. `document` generates `.env.example` from the struct, which is why the contract cannot drift. The verbs come from [`cfgkit/contrib/cli-cobra`](https://github.com/ubgo/cfgkit/tree/main/contrib/cli-cobra) rather than a second binary in this repo — a checker that is not the one operators run in production is a checker of something else.
- Folded the genuinely useful `.ai/` reference docs into `volt/docs/`: `ARCHITECTURE.md`, `STACK.md`, `BACKEND_PATTERNS.md` (the condensed Go cheat-sheet), and `GRAPHQL_EXTENSION.md` — with `volt/docs/` now the single documentation home (see its `README.md` index).
- Consolidated everything Volt-specific into a single deletable root **`volt/`** folder — `README.md` (preserved pitch), `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, `CHANGELOG.md`, `CLAUDE.md` (the Go agent guide), `rules/`, `templates/`, `brand/` (incl. `BRAND_GUIDELINES.md`), and `docs/` — mirroring the Volt Web repo layout. The root `CLAUDE.md` is a thin `@volt/CLAUDE.md` import and `AGENTS.md` a 3-line pointer. All relative links verified with a link-checker.
- Split rules into Volt's and the buyer's: **`volt/rules/`** holds Volt's baseline — `code-standards.md` (the standing engineering bar: full type safety, no hardcoded closed-set values, context-dense comments, modular/no-slop, plus the concrete Go stack rules) + `git-commit.md` + the per-action Go guides. **`.claude/rules/`** is the buyer's space (a `README.md` stub; Volt never writes there). `.claude/settings*.json` stays at the root.
- Volt brand kit under `brand/` (icons, favicon, wordmark, lockups, OG covers, design tokens) driven by `brand.json` + `gen-brand.mjs`.
- `LICENSE` (Volt API Commercial License), `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, `.editorconfig`, and `.gitattributes`.
- `VOLT.md` — the preserved copy of Volt API's original README, so the "built on Volt API" reference survives after a buyer replaces `README.md` with their own app's.

### Changed
- **The CLI builds its kernel lazily.** `volt.Kernel` no longer carries the cobra root command, and `clicmd.AddCommands(rootCmd, kernel)` takes a `KernelFunc` instead of a built kernel. Previously `main()` constructed the whole kernel — config load, Redis ping, non-dev encryption-key check — before cobra could choose a subcommand, so `ping` and `--help` required infrastructure, and a `CONFIG_ENV=prod` invocation carrying a placeholder secret exited *before any command ran*, which made the configuration commands unreachable exactly when they were needed to diagnose it. Commands that need the kernel call the accessor inside `Run`; the rest never trigger it. `webapp.Lazy()` wraps construction in `sync.OnceValue`, so a process still builds at most one.
- **Configuration is now typed Go instead of Pkl.** `modules/config/config.go` is the schema, the defaults and the validation together, loaded via [`github.com/ubgo/cfgkit`](https://github.com/ubgo/cfgkit). Nothing is generated, so nothing can drift from what the code declares. Layers are compiled-in defaults → `.env` → the environment, and **zero input is a valid configuration** — the service runs with no file and no variables set, which is what lets a newcomer clone and run and a test build a config without fixtures.
- `config.Get()` returns `(*Root, error)` and no longer panics; `config.GetOrDie()` keeps the exit as an explicit choice at the call site. The previous loader panicked on a missing directory, turning a configuration mistake into a stack trace at container start — after the rollout, and before the logger existed to record it.
- `CONFIG_ENV` (`dev` / `stag` / `prod`) now selects which **validation rules** apply rather than which file is evaluated. Outside dev the shipped placeholder secrets are refused, so a deploy carrying the default encryption key fails the gate rather than the audit.
- The production image installs no config evaluator, needs no glibc compatibility layer, copies no config files, and fetches nothing from a third-party release URL at build time.
- Documentation follows the code: `modules/config/README.md`, `volt/rules/configuration.md`, `volt/CONTRIBUTING.md`, `volt/CLAUDE.md`, both READMEs, and the deployment + observability guides all describe the Go configuration now.
- Rebranded the project from "Go Boilerplate" to **Volt API**; restructured `README.md` to mirror the Volt (Web) landing page — centered logo header, "Why", "What's inside", features, short getting-started, and FAQ — with all setup moved into `CONTRIBUTING.md`.
- Rewrote `CONTRIBUTING.md` as the full development guide: prerequisites, install, the portless HTTPS dev workflow (`task dev:portless` → `https://volt-api.localhost`), PKL configuration, code generation, migrations, scripts, project structure, API endpoints, deployment, and further docs.
- Corrected task references (`dbent:entg` → `dbent:g`, `task config` → `config:gen`) and the `modules/` monorepo layout across `README.md`, `AGENTS.md`, `CLAUDE.md`, `volt/rules/`, docs, and templates.
- Updated all logging docs to the current stack: `github.com/ubgo/logger` (via `core/pkg/applog`) replaces the retired `gozap`/`nlog`/zap references. Rewrote `volt/rules/logging.md` for the real `ulog` field API (`Err`, `Dur`, `Any` — no `Int`/`Strings`/`Sugar`), and refreshed the instrumentation guides to `otelkit` + `applog.Init` + `errx`.
- License changed from MIT (README-only, no file) to the proprietary Volt API Commercial License.

### Removed
- Pkl schemas, the per-environment Pkl files, the `pkl-gen-go` bindings (893 lines of generated code), the `task config:gen` codegen step, and the Pkl CLI + `pkl-gen-go` prerequisites.
- `core/pkg/volt/weakkey.go` — the weak-key check now lives beside the secrets it guards, in `modules/config/config.go`.
- A duplicate configuration load in the api binary: `webapp.New()` already builds the kernel that holds `RootConfig`.
- `config.Check` / `config.Explain` / `config.Document` — thin wrappers with no production callers once the CLI's `config` command took over. The package's exported surface is now `Get`, `GetOrDie`, `Options` and `EnvFile`; the tests call cfgkit directly through the same `Options()` the application uses.
- Retired the codeskill `.ai/` scaffolding (behaviours, logs, memory stubs, templates, and historical v2 migration transcripts/plans). The repo no longer uses codeskill: agent guidance lives in `CLAUDE.md` → `volt/CLAUDE.md`, per-action rules in `volt/rules/`, and documentation in `volt/docs/`.
