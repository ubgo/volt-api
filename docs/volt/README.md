# Volt API — documentation

**These are [Volt API](../../README.md)'s docs** — the guides that ship with the Go backend boilerplate. They live under `docs/volt/` on purpose: it keeps Volt's documentation namespaced and separable from your own app's docs. When you build on top of Volt API, add your application's documentation directly under `docs/` and leave this `volt/` folder as the boilerplate reference (or delete the parts you don't need).

See also **[VOLT.md](../../VOLT.md)** (the preserved original README) and **[CONTRIBUTING.md](../../CONTRIBUTING.md)** (setup & development guide).
